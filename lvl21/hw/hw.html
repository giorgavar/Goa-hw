Java-ის ისტორია

Java პროგრამირების ენა შეიქმნა 1995 წელს კომპანია Sun Microsystems-ში. მისი მთავარი შემქმნელი იყო ჯეიმს გოსლინგი. Java გახდა პოპულარული თავისი პლატფორმაზე დამოუკიდებლობის გამო.
