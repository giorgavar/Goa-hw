C++ პროგრამირების ენის ისტორია

C++ პროგრამირების ენა შეიქმნა 1980-იან წლებში დანიელი მეცნიერი და პროგრამისტის, ბიარნე სტრაუსტრაპის მიერ. იმ პერიოდში ის მუშაობდა Bell Labs-ში და ეძებდა ისეთ პროგრამირების ენას, რომელიც იქნებოდა სწრაფი, ეფექტური და ამავე დროს მისცემდა პროგრამისტებს უფრო რთული პროგრამების შექმნის საშუალებას. სტრაუსტრაპმა საფუძვლად აიღო C პროგრამირების ენა და მას დაამატა ახალი შესაძლებლობები, განსაკუთრებით ობიექტზე ორიენტირებული პროგრამირების ელემენტები, როგორიცაა კლასები და ობიექტები. თავდაპირველად ენას ეწოდებოდა „C with Classes“, რადგან იგი ფაქტობრივად C ენის გაფართოებას წარმოადგენდა. 1983 წელს ენას ეწოდა C++, სადაც „++“ ნიშნავს გაზრდას და მიუთითებს, რომ ეს არის C ენის გაუმჯობესებული ვერსია. დროთა განმავლობაში C++ გახდა ძალიან პოპულარული, რადგან აერთიანებდა მაღალ წარმადობას და მოქნილ სტრუქტურას. შემდგომ წლებში შეიქმნა C++-ის სხვადასხვა სტანდარტი, რომლებმაც კიდევ უფრო განავითარეს ენა და დაამატეს ახალი შესაძლებლობები. დღეს C++ ფართოდ გამოიყენება ოპერაციული სისტემების, თამაშების, დრაივერებისა და მაღალი სიჩქარის პროგრამების შექმნაში. C++ (ჩვეულებრივ ქართულად გამოითქმის „სი-პლუს-პლუსი“) — საერთო დანიშნულების პროგრამირების ენა. მისი განვითარება დაიწყო ბიარნ სტრუსტრუპმა 1979 წელს ბელ-ლაბში C პროგრამული ენის გასაძლიერებლად. თავდაპირველად მას C with Classes ერქვა, ხოლო 1983 წელს C++ ეწოდა[1]. 1990-იანი წლებიდან C++ გახდა ერთ-ერთი ყველაზე პოპულარული კომერციული პროგრამირების ენებიდან. C++ პროგრამული ენის სტანდარტის რატიფიკაცია მოხდა 1998 წელს, როგორც ISO/IEC 14882:1998; მისი თანამედროვე ვერსიაა 2003 წლის, ISO/IEC 14882:2003. ამჟამად დამუშავების პროცესშია სტანდარტის ახალი ვერსია (არაფორმალურად ცნობილი როგორც C++0x).

C++ ენის შექმნა

C++ პროგრამირების ენა შეიქმნა 1980-იან წლებში ბიარნე სტრაუსტრაპის მიერ. მისი მიზანი იყო C ენის გაფართოება ობიექტზე ორიენტირებული პროგრამირების შესაძლებლობებით.

C++ ენის განვითარება

წლების განმავლობაში C++ მნიშვნელოვნად განვითარდა. დაემატა ახალი სტანდარტები, როგორიცაა C++98, C++11, C++17 და C++20, რომლებმაც გააუმჯობესეს ენის მოქნილობა და შესაძლებლობები.

საინტერესო ფაქტი

C++ ფართოდ გამოიყენება თამაშების შექმნაში, ოპერაციული სისტემების და მაღალი წარმადობის პროგრამების დასაწერად.
